# Chinese Self-Study Tutor

这是一个面向汉语初学者的自适应 Codex 技能。它可以批改写作、讲解语法和词汇、通过常用词学习汉字、制作测试、回顾反复出现的问题，并支持语音练习。

语言：[英文](../../README.md) · **简体中文** · [德文](README.de.md)

## 快速开始

安装范围：`user`

Codex 可以在汉语学习请求中自动选择该技能。也可以显式调用：

```text
$chinese-self-study-tutor normal：批改这篇日记并讲解主要错误。
```

更多可直接使用的提示词，请参阅[中文快速开始](quickstart.zh-CN.txt)。

## 选择反馈深度

- `quickest`：直接给出答案或订正，并附带声调的拼音。
- `simple`：在答案之外补充关键原因、对比或例句。
- `normal`：提供紧凑的小课，包括中文语序拆解、含义、重点说明和简短练习。
- `detailed`：深入比较用法和语境，并提供针对性练习。
- `full`：形成可复用的学习单元，包括诊断、范例、更完整的练习和后续建议。

除非明确要求省略拼音，否则所有深度都会为教学中的中文提供带声调拼音。老师会保守估计学习者的当前水平；存在多个可能级别时，先按较低级别讲解，只有在反复出现明确证据或用户主动要求时才提高难度。

## 批改方式

在 `normal` 及以上深度，作文和批改可以逐句提供订正后的中文、对应拼音、中文语序拆解、直译、自然翻译、重点讲解和简短练习。例如：

```text
我 / 这两天 / 都 / 居家办公
Wǒ / zhè liǎng tiān / dōu / jūjiā bàngōng
我 / 这两天 / 一直 / 在家工作
自然翻译：这两天我一直在家办公。
```

## 汉字与词汇

讲解不熟悉的汉字时，老师通常先用一小组常用词建立语境，而不是只给孤立的字典释义。例如，**烛**（*zhú*）可以通过 **蜡烛**（*làzhú*）、**烛火**（*zhúhuǒ*）、**烛光**（*zhúguāng*）和 **烛台**（*zhútái*）来理解。这是一种灵活的教学方式，不是固定词数要求。

## 默认设置与归档

- 讲解默认使用英语，也可以随时要求使用德语。
- 中文默认采用普通话、简体字和带声调拼音。
- `normal` 及以上内容会以一个自包含 HTML 文件保存到当前工作区的 `archive` 目录。
- 批改不会修改原始输入文件；同一个归档文件会包含原文、订正和讲解。
- 归档文件名采用 `YYYYMMDD [状态] 标题.html`；同名时增加数字后缀，避免覆盖。

如果提供了输入文件或明确要求输出文件，除非指定 `quickest` 或 `simple`，否则默认至少使用 `normal`。
